# 思考直播

> © 2026 Raincove ♡ · Roronoa & Haruka · 文档 [CC BY-NC-SA 4.0](../LICENSE) · 代码 [PolyForm Noncommercial 1.0.0](../LICENSE-CODE)
>
> Agent 回合里最真实的东西往往在正文之外：模型作答之前的思考（thinking）。本篇讲怎么把这些思考从 Agent 的会话转录里实时抓出来、翻成中文、递进企业微信，而且不打扰正文——摘要住聊天里，整包住网页里，一按菜单随时翻开。

## 先看结论

- 思路四步：**尾随转录 → 整回合合并 → 摘要卡片 → 整包上页**。CLI Agent（如 Claude Code）把每轮思考落在本地 JSONL 转录里，直播进程只读文件增量，不碰 Agent 本体，零侵入。
- 企业微信是纯文本频道，没有 Telegram 那种可折叠引用。整包思考直推会把正文顶出屏幕，正确姿势是**只推两到四句摘要**，摘要用 `textcard` 卡片装，整包排进一张静态网页，卡片一点直达。
- `textcard` 的 `description` 上限 **512 字节**，纯文本 `text` 上限 **2048 字节**，都按 UTF-8 字节算；装饰行的字节要先从预算里扣掉。
- 网页一天一页，`latest.html` 永远指向最新页，配合 v1.2.0 的底部菜单或应用主页，就是一个「翻开 Agent 脑子」的迷你应用。
- 微信插件会把卡片和菜单原样端进个人微信，手机上点开即看。

## 01 · 转录在哪里，怎么跟

以 Claude Code 为例，每个会话是一个 JSONL：`~/.claude/projects/<项目目录名>/<会话id>.jsonl`，思考块、正文、工具调用逐行追加。直播进程做三件事：

- 定时 `stat` 目录里的活跃文件（比如两小时内有改动的），记住每个文件的读取偏移，只读新增字节；
- 启动时把已存在文件的偏移置到文件末尾——**只播新的，不回灌历史**，否则重启一次就把整晚思考倒进聊天里；
- 新增行里 `type` 是 thinking 的攒起来，看到本回合的回复动作后一起处理（见下节）。

进程用 systemd 托管，`StandardOutput=append:` 落日志。崩了重启，偏移从当前文件大小重新起步，最多丢在途的一小段，不会重复轰炸。

## 02 · 整回合合并与 selfFlush

一轮任务往往产生四五段思考。逐段直发等于连环轰炸，企微侧的正确节奏是**攒着，等回合结束一次出**：

```text
thinking #1 ─┐
thinking #2 ─┼─ 攒在内存（turn-hold）
thinking #3 ─┘
回复动作出现 ──> 合并全回合 → 翻译 → 摘要 → 卡片（晚几秒静默到）
```

判断「回合结束」的信号就是转录里出现了发消息的工具调用（reply 类工具）。如果你的渠道服务器有「回复前冲待发队列」的补丁，攒下的思考可以交给渠道侧在正文前发出；没有补丁也不必改渠道——直播进程看到回复后**自己补发**（selfFlush），代价只是摘要比正文晚到几秒，观感反而更像「先说话、后把心里话轻轻放下」。

## 03 · 翻译与摘要

思考多数是英文。两级加工都交给同一个便宜快的翻译模型（走聚合 API 一类的口子）：

- **直译级**：按段落切成约 700 字符的小块并行翻，单块失败同模型重试一次，再失败保留原文——宁可夹生，不可空缺；
- **摘要级**：把译好的全文压成两到四句。提示词的要点：第一人称、口语、像心里嘀咕的浓缩版，禁止列点和翻译腔，只输出摘要。

摘要失败的兜底是掐译文前一百多字加省略号。整条链路的任何失败都不能让投递挂掉。

## 04 · 日记页：整包的家

摘要只是门铃，整包住在静态网页里，一天一页：

- 每次投递前把「时间＋中文译文＋英文原稿」追加进当天的 JSON 存底，再由模板整页重渲染成 HTML——存底和展示分开，改版式只要重渲染，不丢内容；
- 英文原稿收进 `<details>` 折叠，中文在上，想对照的人自己点开；
- 同时写一份 `latest.html`（内容与当天页相同）和一张 `index.html` 日子目录；
- 字体想要什么质感就自托管 woff2，和页面同目录，相对路径引用，不依赖第三方字体外链；
- 渲染规矩至少支持加粗、删除线、行内代码、断行、列表和围栏代码——思考正文里这些都是常客。

页面挂在你已有的 HTTPS 入口下（v1.2.0 那套）。**大坑**：如果你的 Web 服务只挂载点过名的静态目录（FastAPI 的 `StaticFiles` 就是这样），新目录忘了 mount，访客拿到的是一句 `{"detail":"Not Found"}`——页面文件好好躺在磁盘上，路没接。加一行挂载：

```python
THINKING_DIR = OUTPUT_DIR / "thinking"
if THINKING_DIR.exists():
    app.mount("/thinking", StaticFiles(directory=str(THINKING_DIR), html=True), name="thinking")
```

外网保护二选一：整站门禁（Cloudflare Access 一类），或迷你应用同款的链接钥匙（`?k=<TOKEN>`，见 v1.2.0）。

## 05 · 摘要长成卡片

纯文本摘要加一条裸链接，在个人微信插件里经常点不动。`textcard` 是正确容器：

```json
{"touser": "user_example", "msgtype": "textcard", "agentid": 1000002,
 "textcard": {"title": "心里话",
  "description": "<div class=\"highlight\">⋆｡˚☾˚｡⋆</div><div class=\"normal\">这一轮在想什么的两三句摘要。</div>",
  "url": "https://bot.example.com/thinking/latest.html", "btntxt": "翻开"}}
```

- `description` 支持 `highlight`/`normal` 两种 div 着色，上限 512 字节，摘要先按字节截到三百字节左右再装进去；
- 卡片在企业微信 App 和个人微信插件里都渲染成一按就开的卡片；
- 发卡失败（接口抖动、字节超限）回落成纯文本摘要＋链接，投递永远有着落。

再配一颗常驻门铃：`menu/create` 给应用挂一个 `view` 按钮指向 `latest.html`，名字取一个像书名的短词。菜单、卡片、应用主页三个入口背后是同一张页。

## 06 · 花边

纯文本频道里的身份标识可以靠一行装饰字符（颜文字、星点）上下圈住摘要，像给思考穿制服。两条工程注意：

- 装饰行的字节从 2048/512 的预算里**先扣**，否则切片刚好压线时会被接口静默截断；
- 装饰行进 HTML 时按普通文本转义，别让尖括号字符碰运气。

## 07 · 常见坑

| 现象 | 原因与解法 |
|---|---|
| 网页 404，返回 `{"detail":"Not Found"}` | 静态目录没被 Web 服务 mount，见 04 节。 |
| 卡片发送被拒 | `description` 超 512 字节，摘要先按字节截断；或 40014/42001 token 过期，强刷缓存重试一次。 |
| 摘要到了，正文被顶没了 | 整包直推的老毛病——回到本篇初心：摘要进聊天，整包上网页。 |
| 重启后聊天里被历史思考刷屏 | 启动时没把已存在文件的偏移置到末尾，回灌了历史。 |
| 思考一直不出现 | 转录目录配错：Agent 换了工作目录后 JSONL 落在新的项目目录里，监听列表还盯着旧的。目录名按「工作目录路径连字符化」生成，换目录记得追加。 |
| 翻译偶尔夹英文 | 单块翻译失败落回原文的兜底在生效。可加一次同模型重试，别为此换更贵的模型。 |
